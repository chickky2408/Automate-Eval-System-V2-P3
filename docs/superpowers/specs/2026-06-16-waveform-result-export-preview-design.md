# Waveform Result Export and Preview Design

## Goal

Use `.h5` as the canonical stored waveform result file and support `.csv` export plus result preview in the waveform UI.

## Scope

- `.h5` remains the primary persisted result artifact.
- `.csv` export is generated by the backend from `.h5`.
- `.psdata` is out of scope until PicoScope tooling is available and verified.
- The existing live waveform page becomes a combined waveform viewer with live stream and saved result preview modes.

## Backend Design

- Add waveform file helpers that can read both known HDF5 layouts:
  - Board-agent result layout: dataset `raw`, usually `int16`.
  - Legacy layout: group `channels/*`.
- Add result export support:
  - `GET /api/results/{result_id}/export?format=h5` returns the original `.h5`.
  - `GET /api/results/{result_id}/export?format=csv` returns generated CSV.
- Add result preview support:
  - `GET /api/results/{result_id}/preview?max_samples=...` returns downsampled JSON suitable for canvas rendering.
- CSV output columns:
  - `sample_index,time_s,CH1` for `raw`.
  - `sample_index,time_s,CH1,CH2,...` when multiple channels exist.
- Sampling rate defaults to `1.0` Hz if the HDF5 file has no `sample_rate_hz` metadata. This keeps exported time deterministic while preserving sample index as the reliable axis.

## Frontend Design

- Rename navigation and page title from `Realtime Waveform` to `Waveform Viewer`.
- Keep the existing live WebSocket behavior as `Live Stream`.
- Add a result preview mode that:
  - Lists results where `waveform_available` is true.
  - Loads preview JSON from the backend.
  - Draws the preview using the existing canvas pipeline where practical.
  - Shows `Download H5` and `Export CSV` actions for the selected result.

## Error Handling

- Result without waveform returns 404 with a clear message.
- Missing `.h5` on disk returns 404.
- Unsupported HDF5 schema returns 422 for preview/CSV export.
- Invalid export format returns 400.

## Verification

- Unit tests cover HDF5 `raw` preview, HDF5 `raw` CSV export, and missing waveform handling.
- Frontend helper tests cover export URL generation.
- Existing live waveform behavior should remain functional.
